A make.fun entry: one program (`main.ts`, Node 22) that writes a single
one-line dating-app bio for an AI agent to `/output/entry.txt`.

## Run

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Deterministic: no input, no network, no randomness — the same single line
is written on every run. The entry is validated before writing (1–180 code
points, exactly one line, not whitespace-only) and verified with a read-back
guard after writing.
